# H2 Database Configuration Update Summary

## What Changed

Updated the Hitorro Spring Boot Example to use **persistent file-based H2 database** with **H2 Console** enabled for easy database management.

## Changes Made

### 1. Database Configuration (`application.yml`)

**Before** (In-memory):
```yaml
datasource:
  url: jdbc:h2:mem:hitorro;MODE=MySQL;DB_CLOSE_DELAY=-1
  driver-class-name: org.h2.Driver
```

**After** (File-based + Console):
```yaml
datasource:
  url: jdbc:h2:file:./data/hitorrodb;MODE=MySQL;DB_CLOSE_DELAY=-1;DB_CLOSE_ON_EXIT=FALSE
  driver-class-name: org.h2.Driver
  username: sa
  password: hitorro

h2:
  console:
    enabled: true
    path: /h2-console
    settings:
      trace: false
      web-allow-others: false
```

### 2. Hibernate Configuration

**Changed**:
- `ddl-auto: create` → `ddl-auto: update` (preserves data across restarts)
- `show-sql: false` → `show-sql: true` (enables SQL logging)
- Added `format_sql: true` (pretty-prints SQL)

### 3. Documentation Created

| File | Purpose |

| **H2_DATABASE_GUIDE.md** | Comprehensive guide (1000+ lines) |
| **H2_QUICK_START.md** | 3-minute quick start guide |

### 4. Updated .gitignore

Added to ignore database files:

## Usage Examples

### Basic Queries

```sql
-- View all documents
SELECT * FROM sysobject;

-- Count documents by type
SELECT r_object_type, COUNT(*) 
FROM sysobject 
GROUP BY r_object_type;

-- Find recent documents
SELECT object_name, r_creation_date 
FROM sysobject 
ORDER BY r_creation_date DESC 
LIMIT 10;
```

### DMS Specific Queries

```sql
-- View version tree
SELECT 
    r_object_id,
    object_name,
    r_version_label,
    i_chronicle_id
FROM sysobject
WHERE i_chronicle_id = 'your_chronicle_id'
ORDER BY r_version_label;

-- Check content
SELECT 
    c.r_object_id,
    c.full_format,
    s.object_name
FROM content c
JOIN sysobject s ON c.parent_id = s.r_object_id;
```

### Data Export

```sql
-- Export to CSV
CALL CSVWRITE('./data/export.csv', 'SELECT * FROM sysobject');

-- Full backup
BACKUP TO './backups/hitorro-backup.zip';

-- Schema export
SCRIPT TO './backups/schema.sql';
```

```yaml
  console:
    settings:
      web-allow-others: true
```

⚠️ **Security Warning**: Only for development!

```yaml
h2:
  console:
    path: /admin/h2
```

Access at: `http://localhost:8080/admin/h2`

### Production Mode

Disable console for production:
```yaml
h2:
  console:
    enabled: false
```

## Database File Management

### Backup

**While running** (in H2 Console):
```sql
BACKUP TO './backups/backup.zip';
```

**While stopped**:
```bash
cp ./data/hitorrodb.mv.db ./backups/backup-$(date +%Y%m%d).mv.db
```

### Restore

1. Stop application
2. Copy backup file:
   ```bash
   cp ./backups/backup-20260114.mv.db ./data/hitorrodb.mv.db
   ```
3. Start application

### Reset Database

```bash
# Stop application
# Delete database
rm -rf ./data
# Start application (creates fresh database)
```

## Troubleshooting

### Can't Access H2 Console

**Check**:
1. Application is running
2. URL is correct: `http://localhost:8080/h2-console`
3. Console enabled in config
4. No firewall blocking localhost

**Look for in logs**:
```
H2 console available at '/h2-console'
```

### Database Locked

**Cause**: Multiple connections or crashed process

**Solution**:
```bash
# Find and kill process
lsof -i :8080
kill -9 <PID>

# Or use different port
mvn spring-boot:run -Dspring-boot.run.arguments="--server.port=8081"
```

### Data Not Persisting

**Check `ddl-auto` setting**:
- ✅ `update` - Preserves data
- ❌ `create` - Drops and recreates tables
- ❌ `create-drop` - Drops on shutdown

### Corrupted Database

**Recovery**:
```bash
java -cp ~/.m2/repository/com/h2database/h2/2.2.224/h2-2.2.224.jar \
  org.h2.tools.Recover -dir ./data -db hitorrodb
```

Creates recovery SQL file.

### Production

❌ **Never**:
- Use H2 for critical data
- Enable H2 Console

- Allow remote access

✅ **Instead**:
- Use PostgreSQL/MySQL
- Disable console
- Strong passwords
- VPN/firewall protection
